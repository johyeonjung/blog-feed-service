# Blog Feed Service

Instagram 스타일의 피드형 SNS 백엔드 프로젝트입니다
사용자는 회원가입 후 게시글을 업로드하고, 이미지와 함께 자신의 일상을 공유할 수 있습니다. JWT 기반 인증을 적용했으며 댓글/대댓글 기능을 구현했습니다
현재는 Instagram의 핵심 기능을 참고하여 좋아요, 팔로우, 프로필, 검색 기능을 추가하고 있습니다

## 기술 스택

- Java 21
- Spring Boot
- Spring Security
- JWT
- OAuth2
- MyBatis
- MySQL
- Maven

## 구현 기능

### 사용자
- 회원가입
- 로그인
- JWT 인증
- OAuth2 로그인

### 게시글

- 게시글 작성
- 게시글 조회
- 게시글 수정
- 게시글 삭제
- 이미지 업로드

### 댓글

- 댓글 작성
- 대댓글 작성
- 댓글 조회

## 개발 예정 기능
- 스토리
- 좋아요
- 팔로우 / 언팔로우
- 프로필 페이지
- 게시글 검색
- 페이징 처리
- 사용자 게시글 모아보기

## 프로젝트 목표

실제 SNS 서비스 구조를 이해하기 위해 Instagram의 핵심 기능을 직접 구현하는 것을 목표로 개발하고 있습니다!
